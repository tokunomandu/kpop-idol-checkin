# ideeeat

A K-pop themed “idol-location check-in” website concept built as a front-end prototype.

## Features
- Idol filter chips and city quick-picks
- Searchable list of places
- Save/favorite and check-in interactions
- Detail modal for each place
- Responsive design for desktop and mobile
- Mock data so the demo works without a backend

## Run locally
Open `index.html` directly in a browser, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project structure
- `index.html` — main page structure
- `styles.css` — branding and responsive styles
- `app.js` — mock data and UI interactions

## Notes
This is a front-end MVP meant for early product exploration. It is intentionally static and easy to extend with real APIs, authentication, and a backend later.
